## Featured project

### [Project Knowledge AI](https://github.com/AngelUch27/project-knowledge-ai)

A private, tool-using knowledge agent on Google Cloud. Drop documents, paste a GitHub repository or connect a SharePoint site; the agent searches them, reads the relevant passages and answers with clickable sources.

- **Agent loop:** bounded Gemini function calling (max 6 steps) over read tools and action tools
- **Human in the loop:** actions that modify data stop and wait for confirmation in the UI
- **Retrieval:** Vertex AI Search, with stale results filtered against the bucket as source of truth
- **Ingestion:** event-driven and keyless (Cloud Storage events, content hashing, daily Cloud Scheduler re-sync)
- **Sources:** PDF, DOCX, PPTX, XLSX, Markdown, HTML, JSON, GitHub repositories, SharePoint Online

`Python` `Gemini` `Vertex AI Search` `Cloud Run` `Eventarc` `RAG`
